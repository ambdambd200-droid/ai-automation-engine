# Deploy AI Automation Engine to Render.com (free)

**Goal:** Move the engine off your laptop to a free Render web service so it runs 24/7 and doesn't heat your device. Your scripts (hunt.py, keyhub_client) will point to the Render URL instead of `127.0.0.1:5000`.

**What you get (Render Free Tier, no credit card):**
- 512 MB RAM
- Spins down after 15 min of no requests (cold-starts in ~30-60 sec on next hit)
- 750 hours/month (enough for 24/7 if you ping it every 14 min)
- HTTPS URL: `https://ai-automation-engine.onrender.com`

**WSGI server:** Uses `waitress` (not `gunicorn`) — waitress works on both Windows and Linux, so the same code runs locally and on Render.

---

## Step 1 — Push the engine folder to a new GitHub repo

1. Sign in to GitHub (create a free account at https://github.com if you don't have one).
2. Create a **new private repository** called `ai-automation-engine`.
3. Use **GitHub Desktop** to push the engine folder (recommended — no command-line git needed):
   - Download: https://desktop.github.com
   - File → Add local repository → choose `C:\Users\A\Desktop\Money\ai-automation-engine`
   - Click "Publish repository" → uncheck "Keep this code private" if you want public, or leave checked for private
   - Done

   **OR** with command-line git (if you install it later):
   ```powershell
   Set-Location -LiteralPath "C:\Users\A\Desktop\Money\ai-automation-engine"
   git init
   git add .
   git commit -m "Initial engine"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/ai-automation-engine.git
   git push -u origin main
   ```

4. Confirm the push worked by visiting your GitHub repo in the browser.

---

## Step 2 — Sign up on Render.com

1. Go to https://render.com and click **Get Started for Free**.
2. Sign up with **GitHub** (easiest — one click).
3. Confirm your email if Render asks.

---

## Step 3 — Create the web service

1. From the Render dashboard, click **New +** → **Blueprint**.
2. Connect your GitHub account if not already connected.
3. Select the `ai-automation-engine` repository.
4. Render will auto-detect `render.yaml` and show a preview. Click **Apply**.
5. Wait for the first build to complete (~2-3 min). You'll see "Live" when ready.

If the Blueprint option doesn't appear or fails, use the manual route:
1. Click **New +** → **Web Service**.
2. Connect the repo.
3. Fill in:
   - **Name:** `ai-automation-engine`
   - **Region:** Oregon
   - **Branch:** main
   - **Runtime:** Python 3
   - **Build command:** `pip install --upgrade pip && pip install -r requirements.txt`
   - **Start command:** `waitress-serve --host 0.0.0.0 --port $PORT --threads 4 wsgi:application`
   - **Instance type:** Free
4. Click **Create Web Service**.

---

## Step 4 — Set environment variables

In the Render dashboard → your service → **Environment** tab, add:

| Key | Value | Notes |
|---|---|---|
| `GROQ_API_KEY` | (paste your Groq key — `gsk_...`) | Same as your local key |
| `OPENAI_API_KEY` | (paste your OpenAI key) | Optional fallback |
| `SECRET_KEY` | (auto-generated by Render) | Already set if Blueprint worked |
| `PYTHON_VERSION` | `3.12.0` | Optional, Render auto-detects |

Click **Save Changes** — Render will redeploy automatically.

---

## Step 5 — Verify the deployment

Wait for the deploy to show "Live" (~1-2 min). Then test in your browser:

- `https://ai-automation-engine.onrender.com/health` → should show `{"status":"running",...}`
- `https://ai-automation-engine.onrender.com/workflows` → should list your YAML workflows
- `https://ai-automation-engine.onrender.com/proxy/stats?days=7` → should show `{"stats":[], "days":7}`

If you get "Application failed to respond", check the **Logs** tab in Render — common issue is missing `gunicorn` in requirements (already added).

## Step 6 — Point keyhub_client at the Render URL

On your local machine, set the `ENGINE_URL` env var so all scripts use the cloud engine:

**PowerShell (one-time, for current session):**
```powershell
$env:ENGINE_URL = "https://ai-automation-engine.onrender.com"
```

**PowerShell (permanent, for your user account):**
```powershell
[System.Environment]::SetEnvironmentVariable("ENGINE_URL", "https://ai-automation-engine.onrender.com", "User")
# Then close and reopen the terminal
```

Now `hunt.py`, `keyhub_client.py`, and any other script will route to the cloud engine automatically.

---

## Step 7 — Keep the free tier awake (optional)

Render free tier sleeps after 15 min of inactivity. To keep it awake, you can:

**Option A: Cron ping (easiest)**
```powershell
# Add to Windows Task Scheduler — runs every 14 min
$url = "https://ai-automation-engine.onrender.com/health"
Invoke-RestMethod -Uri $url -UseBasicParsing
```

**Option B: UptimeRobot (free, no account needed for simple usage)**
1. Go to https://uptimerobot.com (free account)
2. Add a new monitor: HTTPS, your URL, 14-min interval
3. Done — it pings for you

**Option C: Accept the cold start**
- First request after sleep takes 30-60 sec (Render wakes the container)
- Subsequent requests are fast
- hunt.py --gather will be slow the first time of the day, then fast

---

## Step 8 — Disable the local engine (optional)

Once the cloud engine is stable, you can stop the local auto-start:

1. Open `shell:startup` (Windows + R, type `shell:startup`)
2. Find and delete the shortcut that runs `start_engine_hidden.vbs`
3. The local engine is now off — all scripts use the cloud

**To go back to local:** just run `start_engine.bat` from the engine folder.

## Troubleshooting

**Build fails with "Module not found: waitress"**
- Confirm `waitress==3.0.0` is in `requirements.txt` (already added)
- Render log will show the exact missing module

**"Application failed to respond" on first request**
- Wait 30-60 sec — Render is spinning up the container
- Try again

**Workflows return 404**
- The workflows/ folder is in the repo — Render serves from root
- Test: `https://ai-automation-engine.onrender.com/workflows` should list them

**GROQ_API_KEY not working on Render**
- Confirm the env var is set in Render dashboard
- Re-deploy after adding env vars
- Test: `curl -X POST https://ai-automation-engine.onrender.com/proxy/ai -H "Content-Type: application/json" -d "{\"prompt\":\"say hi\"}"`
