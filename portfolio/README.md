# GitHub Pages Deployment for Portfolio

## Current Setup
The portfolio is in the `/portfolio` directory at the root of the repository.

## To Deploy:
1. Go to: `https://github.com/ambdambd200-droid/ai-automation-engine/settings/pages`
2. Source: **Deploy from a branch**
3. Branch: `main`
4. Folder: `/portfolio`
5. Click **Save**
6. Wait 1-2 minutes
7. Your URL: `https://ambdambd200-droid.github.io/ai-automation-engine/portfolio/`

## Files in /portfolio:
- index.html
- styles.css
- script.js
- README.md

## Note:
The portfolio is already committed to the main branch. Just enable GitHub Pages with the settings above.
